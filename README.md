# 🤖 AI Mini Projects

Two Python/Flask projects.

---

## 👓 Visual Try-On Glasses
Real-time virtual glasses try-on using webcam face detection.
- **Tech:** Python, Flask, OpenCV, cvzone
- **How it works:** Detects face/eyes via webcam, overlays selected glasses frame in real time, resized to fit.
- **Files:** `tryon/app.py`, `tryon/templates/index.html`

## 🍽️ Restaurant Chatbot
Rule-based NLP chatbot answering restaurant FAQs (menu, prices, hours, delivery, reservations).
- **Tech:** Python, Flask, NLTK
- **How it works:** Matches user input to predefined intent patterns and replies instantly via a Flask API.
- **Files:** `chatbot/main.py`, `chatbot/templates/index.html`

---

## ✨ Common Stack
Python · Flask · OpenCV / NLTK
